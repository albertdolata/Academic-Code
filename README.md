# Academic Code

This repository is a curated collection of engineering projects and laboratory exercises completed at the **Lodz University of Technology** (Faculty of EEIA). Each project represents a different stage of my technical education, moving from core programming logic to complex hardware-software systems.

## Project Overviews

### 1. Space Cannon Game (C)
* **Course:** Fundamentals of Programming
* **Timeline:** 2nd Semester
* **Description:** An arcade game developed to practice procedural programming logic. 
* **Focus:** Implementation of a main game loop, real-time user input handling, and basic physics for collision detection using C structures.

### 2. Sensor Management System (C++)
* **Course:** Object-Oriented Programming
* **Timeline:** 3rd Semester
* **Description:** A simulated base station system designed to manage various environmental sensors.
* **Focus:** Practical application of **Polymorphism**, **Inheritance**, and custom **Exception Handling**. It features operator overloading for intuitive management of sensor objects.

### 3. FIFO Buffer Module (VHDL)
* **Course:** Programmable Logic Devices
* **Timeline:** 4th Semester
* **Description:** Hardware implementation and verification of a digital FIFO queue.
* **Focus:** Understanding digital logic and signal synchronization, including clock-edge triggers and synchronous resets. 
* **Verification:** Validated through a dedicated **Testbench** to monitor state flags like Full, Empty, and Error.
